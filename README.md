# GMX Public Build Check

This public repository is a **zero-cost compilation environment** for the public GMX smart-contract source tree.

Scope and safeguards:
- Builds only publicly available GMX source, pinned to a specific upstream commit.
- No exploit proofs of concept, private vulnerability reports, sensitive findings, credentials, or wallet keys.
- No execution or transaction submission against deployed mainnet or public-testnet smart contracts.
- GitHub Actions uses a **standard** hosted runner only and never requests paid larger runners.
- No paid cloud platforms, infrastructure provisioning, secrets, or production deployments.

For responsible vulnerability research, work privately and report any confirmed vulnerability through the official Immunefi GMX program.
